# Estate Heritage - Portfólio Imobiliário de Luxo

Este é um projeto de portfólio para corretores de imóveis de alto padrão, desenvolvido com um design moderno, sofisticado e totalmente responsivo.

## 🚀 Funcionalidades

- **Página Inicial Impactante:** Seção hero com busca e vitrine de imóveis em destaque.
- **Listagem de Imóveis:** Filtros avançados por preço, quartos, vagas e localização.
- **Detalhes da Propriedade:** Ficha técnica completa, diferenciais, galeria de imagens e mapa de localização.
- **Conversão Otimizada:** Integração com Sheet Monkey para formulários e API direta do WhatsApp.
- **Design Responsivo:** Experiência fluida em desktops, tablets e smartphones.


## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica.
- **Tailwind CSS:** Estilização moderna e utilitária.
- **JavaScript (Vanilla):** Interações e lógica de navegação.
- **Google Fonts:** Tipografia elegante (Noto Serif e Sans).
- **Lucide Icons:** Ícones minimalistas.

## 🔧 Como Usar

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/estate-heritage.git
   ```

2. **Configurar APIs:**
   - No arquivo `detalhes.html` e `contato.html`, substitua `YOUR_SHEET_MONKEY_URL` pela URL do seu formulário no Sheet Monkey.
   - Localize o link do WhatsApp e insira o seu número de telefone.

3. **Deploy:**
   O projeto é estático. Você pode usar o [Netlify](https://www.netlify.com/), [Vercel](https://vercel.com/) ou [GitHub Pages](https://pages.github.com/) para hospedar gratuitamente.
